# Java Loop Programs

A collection of basic Java programs created to understand and practice different looping concepts and control statements in Java.

## 📌 About the Project

This repository contains Java programs covering different types of loops, nested loops, and loop control statements. These examples help beginners understand how loops work and how they are used to execute statements repeatedly.

## 📂 Programs Included

| File Name | Description |
|---|---|
| `ForTest.java` | Demonstrates the use of a for loop. |
| `WhileTest.java` | Demonstrates the use of a while loop. |
| `DoWhileTest.java` | Demonstrates the do-while loop. |
| `EnhancedForLoop.java` | Demonstrates the enhanced for loop. |
| `nested_loop.java` | Demonstrates nested loops. |
| `ContinueBreak.java` | Demonstrates break and continue statements. |

## 🛠️ Technologies Used

- **Programming Language:** Java
- **IDE:** Visual Studio Code
- **JDK:** Java Development Kit

## ⚙️ Getting Started

### Prerequisites

- Install Java JDK.
- Install Visual Studio Code or any Java-supported IDE.
- Configure Java in your system.

### How to Run

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder in VS Code.

3. Open the terminal and navigate to the project directory.

4. Compile any Java program:

   ```bash
   javac ForTest.java
   ```

5. Run the compiled program:

   ```bash
   java ForTest
   ```

Replace `ForTest` with the class name of the program you want to execute.

## 🎯 Learning Objectives

- Understand different types of loops in Java.
- Learn how to use nested loops.
- Understand the difference between `for`, `while`, and `do-while` loops.
- Practice enhanced for loops.
- Learn the use of `break` and `continue` statements.
- Improve basic Java programming and logical thinking.
